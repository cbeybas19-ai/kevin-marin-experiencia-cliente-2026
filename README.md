# Actividad 7 — Kevin Marin

Borrador académico para revisión y personalización.

Tema: experiencia del cliente y fidelización en pequeños comercios.

## Publicación

Este sitio está preparado para GitHub Pages desde la raíz de la rama `main` (`Settings → Pages → Deploy from a branch`). No contiene datos reales de clientes; el comercio y el caso son ficticios.

## Contenido

- `index.html`: blog con recorrido interactivo, caso, indicador, prácticas de privacidad y bibliografía.
- `styles.css`: diseño editorial adaptable a móvil.
- `script.js`: selector interactivo de etapas del recorrido.
- `presentacion.html`: presentación web con navegación por botones y flechas del teclado.
- `KevinMarin_Presentacion_Actividad7.pptx`: versión PowerPoint editable para descargar.
- `slides.css` y `slides.js`: estilo y controles de la presentación web.

El caso de la tienda es ficticio y los materiales son borradores educativos para revisión y personalización.
